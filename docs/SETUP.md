# 설치와 연결

## 1. 맥북 준비

1. 시스템 설정 → 일반 → 공유 → **화면 공유**를 켭니다.
2. 같은 줄의 ⓘ → **컴퓨터 설정**에서 암호를 정하고
   **"VNC 사용자가 암호로 제어하도록 허용"** 을 켭니다.
3. 맥 주소를 확인합니다. 시스템 설정 → Wi-Fi → 연결된 네트워크 → 세부사항 → IP 주소.
4. 태블릿과 맥이 같은 네트워크에 있어야 합니다.

터미널로 상태를 확인하려면 다음을 실행합니다.

```bash
tools/mac-setup.sh
```

## 2. 앱 설치

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

태블릿에서 USB 디버깅을 켜려면 설정 → 태블릿 정보 → 빌드 번호를 일곱 번 누릅니다.
그다음 개발자 옵션 → USB 디버깅을 켭니다.

## 3. 키보드 켜기

앱 안에서만 쓰는 키보드는 따로 켤 필요가 없습니다. 원격 화면 위쪽 **키보드** 버튼을 누르면 나옵니다.

다른 앱에서도 쓰려면 설정 → 시스템 → 언어 및 입력 → 화면 키보드 → 키보드 관리에서
**PadDeck 키보드**를 켭니다.

## 4. 애플 트랙패드에 대해

애플 매직 트랙패드는 표준 마우스 신호가 아니라 애플 전용 신호를 보냅니다.
안드로이드 커널에 그 신호를 읽는 드라이버(`hid-magicmouse`)가 들어 있으면 마우스로 인식되고,
없으면 블루투스로 붙어도 커서가 움직이지 않습니다.

확인은 다음으로 합니다.

```bash
tools/probe-device.sh
```

- `Magic Trackpad`가 입력 장치 목록에 보이면 커서 이동과 두 손가락 스크롤이 대개 동작합니다.
- 목록에 없으면 안드로이드가 트랙패드 신호를 아예 받지 못하는 상태입니다.
  이때는 앱이 손댈 수 있는 영역이 아닙니다. 커널 드라이버가 필요합니다.

앱이 확실히 바꿀 수 있는 것은 **원격 화면 안에서의 트랙패드 느낌**입니다.
원격 화면 위쪽 **마우스 잡기**를 누르면 앱이 포인터를 붙잡아 두 손가락 스크롤,
오른쪽 클릭, 세 손가락 미션 컨트롤을 직접 해석합니다.

## 5. 조작 요약

| 동작 | 결과 |
|---|---|
| 한 손가락 끌기 | 커서 이동 |
| 한 손가락 톡 | 왼쪽 클릭 |
| 두 번 톡 하고 끌기 | 드래그 잠금 |
| 두 손가락 문지르기 | 스크롤 |
| 두 손가락 톡 | 오른쪽 클릭 |
| 세 손가락 위/아래 | 미션 컨트롤 / 앱 보기 |
| 세 손가락 좌/우 | 데스크톱 전환 |
| 위쪽 키보드 버튼 | 노트북형 키보드 |
| 아래 ⌃ ⌥ ⌘ ⇧ | 맥에 눌린 상태로 유지 |
